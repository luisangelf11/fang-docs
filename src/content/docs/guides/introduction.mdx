**Fang JS** es un micro-framework minimalista, ultraligero y fuertemente tipado diseñado para Node.js. Su filosofía se basa en eliminar dependencias externas innecesarias para centrarse en lo que realmente importa: el desarrollo de APIs REST de alto rendimiento.

<Aside type="tip" title="Estado del Proyecto: Versión 1.0.3">
  Estás explorando la **versión 1.0.3** de Fang JS. Esta es nuestra primera
  entrega oficial, diseñada para demostrar el potencial de un framework
  *zero-deps* sólido y funcional desde el primer día. Lo que ves aquí es solo el
  comienzo de la manada. Dependiendo del apoyo, las estrellas en GitHub y la
  adopción de la comunidad, **Fang JS está destinado a evolucionar
  drásticamente**, incorporando nuevas funcionalidades y optimizaciones que
  llevarán el desarrollo en Node.js al siguiente nivel. **El futuro de Fang
  depende de ustedes. ¡Hagámoslo crecer!**
</Aside>

## ¿Por qué existe Fang JS?

Fang JS nació de una idea radical: **¿Qué pasaría si un framework no intentara hacerlo todo, sino que hiciera una sola cosa a la perfección?**

En un ecosistema saturado de abstracciones pesadas y "magia negra" que oculta el funcionamiento real de las peticiones, Fang JS se erige como una capa delgada, transparente y extremadamente rápida construida directamente sobre los módulos nativos de Node.js.

<Aside type="caution" title="Filosofía de Poder Minimalista">
  No creemos en las "cajas negras". Si quieres una funcionalidad (Sesiones, JWT,
  etc.), tú la integras. Nosotros te damos las herramientas (Contexto, Cookies,
  Middlewares), tú pones la lógica.
</Aside>

## Pilares Fundamentales

<CardGrid>
  <Card title="Sin dependencias pesadas" icon="puzzle">
    Solo **Zod** vive en tu `node_modules`. Esto garantiza máxima seguridad, un
    footprint mínimo y validaciones de grado industrial.
  </Card>
  <Card title="Tipado de Primer Nivel" icon="seti:typescript">
    Escrito nativamente en TypeScript. El objeto `Context` unificado elimina la
    necesidad de manejar `req` y `res` por separado.
  </Card>
  <Card title="Arquitectura de Cebolla" icon="layers">
    Soporte total para el patrón de middleware asíncrono (`await next()`),
    permitiendo ejecutar lógica antes y después de tus rutas.
  </Card>
  <Card title="Seguridad por Defecto" icon="shieldCheck">
    Gestión de cookies con atributos de seguridad (HttpOnly, Secure, SameSite)
    tratados como ciudadanos de primera clase.
  </Card>
</CardGrid>

## Fang JS frente a la industria

A diferencia de otros frameworks que arrastran decenas de dependencias transitivas, Fang JS mantiene su árbol de dependencias limpio.

| Característica   | Express.js               | Koa.js                 | **Fang-js**🐺                     |
| :--------------- | :----------------------- | :--------------------- | :-------------------------------- |
| **Filosofía**    | "Incluye lo básico"      | Minimalista / Base     | **Estrictamente Tipado / Seguro** |
| **Validación**   | Manual / Terceros        | Terceros               | **Integración Nativa con Zod**    |
| **Middleware**   | Basado en Callbacks      | Async (Modelo Cebolla) | **Async (Modelo Cebolla)**        |
| **TypeScript**   | Vía `@types/express`     | Vía `@types/koa`       | **Nativo (Soporte de primera)**   |
| **Cookies**      | Requiere `cookie-parser` | Integrado (sin Zod)    | **Nativo + Esquema Zod**          |
| **Dependencias** | ~30+ transitivas         | ~20+ transitivas       | **1 (Zod)**                       |

## ¿Es para ti?

Si eres un desarrollador que valora la **mantenibilidad**, la **seguridad real** y una **arquitectura limpia** sin sacrificar la velocidad de ejecución, Fang JS es tu herramienta. Es ideal para microservicios donde cada milisegundo de latencia y cada megabyte de memoria cuentan.
